# 📊 Excel Habit Tracker

A smart habit tracker built using Microsoft Excel.

## ✨ Features
- Daily habit tracking using checkboxes
- Automatic progress calculation
- Visual progress using sparklines
- Monthly tracking support

## 🛠 Tools Used
- Microsoft Excel
- Formulas (COUNTIF, IF, TODAY)
- Conditional Formatting
- Sparklines

## 🚀 Use Case
Helps individuals track daily habits and improve productivity.
